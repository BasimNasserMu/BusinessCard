# BusinessCard

A modern, responsive digital business card built with Tailwind CSS.

## Features

- 🎨 Built with Tailwind CSS
- 🌓 Auto light/dark mode based on system preferences
- 📱 Fully responsive design
- ✨ Smooth animations and transitions
- 🔗 Social media links (LinkedIn, Email, WhatsApp, GitHub, Twitter, Instagram)

## Setup

1. Replace `profile.jpg` with your photo
2. Edit `index.html` to update:
   - Your name
   - Your title/position
   - Social media links

## Deployment to GitHub Pages

This repo is configured to automatically deploy to GitHub Pages when you push to the main branch.

### Enable GitHub Pages:

1. Go to your repository settings
2. Navigate to **Pages** (under "Code and automation")
3. Under "Build and deployment":
   - Source: **GitHub Actions**
4. Push your changes to the `main` branch
5. Your site will be live at: `https://basimnassermu.github.io/BusinessCard/`

The deployment workflow is defined in `.github/workflows/deploy.yml`

## Local Development

Simply open `index.html` in your browser. No build process required!
